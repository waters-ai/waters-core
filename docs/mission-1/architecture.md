## Протоколы обмена

### Между агентами миссии (Redis pub/sub)

```
Канал: mission:state
Формат: JSON
Публикует: CoordinatorAgent / любой агент
Тело: {
  "type": "state_update",
  "agent": "collector.1",
  "state": "collecting|analyzing|idle|error",
  "payload": {}
}
```

```
Канал: mission:findings
Формат: JSON
Публикует: AnalyzerAgent / PatternMatcherAgent
Тело: {
  "type": "new_finding",
  "finding_id": "uuid",
  "source": "nasa_fireball_20260515",
  "confidence": 0.87,
  "data": { ... }
}
```

### Между миссией и центром (HTTP bridge → Kafka)

```
Миссия → Центр (findings):
  POST https://238.bridge.waters/mission/1/findings
  Body: { findings: [...], heartbeat: {...} }

Центр → Миссия (orders):
  GET https://238.bridge.waters/mission/1/orders
  Response: { orders: [...], timestamp: "..." }
```

## Уровни автономии

| Уровень | Описание | Условие |
|---------|----------|---------|
| **L0** | Полная зависимость от центра | Есть связь с 238, есть DeepSeek API |
| **L1** | Автономия LLM | Связь с 238 есть, DeepSeek API нет → Ollama |
| **L2** | Полная автономия | Нет связи с 238, нет API → всё локально, queue хранит данные для отправки |
| **L3** | Аварийная | Отказ сервера → systemd restart, восстановление из RocksDB |
