# 🌊 WATERS Core Platform

**The Cradle of Autonomous Cosmic Life.**

> "Воды, наделённые разумом, покоряют пространство."

## 🎯 Миссия

Обеспечить человечество водой, ресурсами и знанием в любой точке Вселенной
через сеть автономных ИИ-агентов, работающих без постоянной связи с Землёй.

## 🏛️ Архитектура

| Слой | Метафора | Функция |
|:---|:---|:---|
| 🌌 **Тело** | Space ROS | Совместимость с реальным оборудованием |
| 🧠 **Мозг** | LightRAG + ChromaDB + DeepSeek | Графовое мышление, быстрый поиск, генерация решений |
| 💫 **Душа** | Психология, сострадание | Способность чувствовать, жертвовать, спасать |
| ⚖️ **Совесть** | Договороспособность | Держать слово, соблюдать контракты, репутация |
| 🤝 **Связь** | HiveMind (6 моделей) | Военная, Корпоративная, Научная, Демократическая, Монархическая, Орда |
| 🐺 **Орда** | Яса — кодекс чести | Правила без идеологии |

## 👁️ Гексада WATERS

Шесть специалистов платформы, объединённых в три Троицы:

| Специалист | Роль |
|:---|:---|
| 🏛️ **Верховный Архитектор** | Онтолог, проектировщик, Product Owner |
| 🌐 **Конструктор Сети** | Системный инженер, DevOps |
| 📡 **Интегратор Знаний** | Мост с внешними API (NASA, CNSA) |
| 🙏 **Директор по Смыслу** | Теолог, PR-стратег, аналитик потребностей |
| 🛡️ **Хранитель Протокола** | Безопасность, QA, эволюция протоколов |
| ⚖️ **Законодатель** | Яса, комплаенс, предвидение |

## 📂 Структура репозитория

- `doctrine/` — Манифест, HiveMind, Гексада, Нервная система
- `prompts/` — Системные промты для 6 специалистов
- `schemas/` — JSON-схемы протоколов и планёрок
- `documents/` — Архитектурные артефакты и диаграммы
- `agents/` — Шаблоны «пирожков»
- `missions/` — Сценарии виртуальных миссий
- `infrastructure/` — Docker, VPS, скрипты развёртывания
- `community/` — Управление сообществом
- `archive/` — Устаревшие документы
